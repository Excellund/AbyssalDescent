# Readable Pause Options

Pause Options now uses the same physical sizing as the updated Pause and Oath screens. Its settings copy and selectors remain 18 pixels at 960×540 and 1280×720, despite the game's stretched 2560×1440 canvas. The title and Back action stay fixed while the settings body scrolls. Keyboard focus brings offscreen controls into view and returns to the Options action when Back is activated.

The existing sliders, display/resolution selectors and telemetry checkbox keep their original settings callbacks. The change reparents those controls into a scrolling body, adds responsive positioning and uses a local font/theme for the panel and its dropdowns. Slider tracks have visible contrast, the telemetry checkbox has outlined checked/unchecked icons, and its focus border stays inside the clipped viewport. A resize during an entrance animation cancels the old animation before applying the new layout.
